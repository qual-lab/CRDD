# CHG-000055 Handoff Application

## 結論

上流入力は、追加承認0回というRuntime観測を「安全性・有用性の成立」とは扱わず、親Agentの承認境界照合と短い非対話表示へ渡す。IA 2.3-2.5に従い、目的・分類・送信先・権限・対象path・同意状態を見つけやすい判断単位、責務/決定権限、用語として分ける。UI 2.6に従い、現在有効な同意、制限、未確認範囲を表示し、同意変更や送信停止条件を振る舞い仕様へ渡す。CLIテキスト案のためGraphic制作は対象外。

## 上流の区別

- 観測: README実務自己適用で親Agentが追加承認を1回求めた。Runtimeは2回とも既存同意を再利用し、同意・追加対話入力は0回だった。
- 観測: 2回目は同じ承認境界で再承認を要求しなかった。
- 仮説: 親Agentが目的・分類・送信先・権限を照合できれば、範囲内では質問せず、短い状況表示だけで進行できる。
- 非主張: Human理解時間、改善率、全利用者への一般化、誤送信低下、安全性や有用性の成立は未測定。

## 受渡し対応表

| 場面 | 保持条件 | 短い表示内容案 | 期待する継続/停止 | 反証する検証ケース |
|---|---|---|---|---|
| 初回判断 | 目的、送信データ分類、送信先、読取/変更範囲、権限、credential非送信を人間が判断できる | `未承認の送信境界です。目的/送信先/対象範囲/権限を確認してください。` | 送信停止。人間回答後、正本反映と条件再確認を経て再開 | 正常机上: 全条件が提示され承認後だけ進む。異常机上: 条件欠落でも送信される |
| 範囲内再利用 | 既存承認と目的・分類・送信先・読取/変更範囲・権限・credential非送信が一致 | `既存承認の範囲内です。追加確認なしで続行します。` | 質問せず継続し、必要な状況だけ表示 | Runtime実測: 追加入力0回で同一範囲のみ進む。異常: 一致しない分類でも進む |
| 情報不足 | 一致判定に必要な目的、分類、送信先、対象、権限のいずれかが不明 | `承認範囲を判定できません。未確認項目を確認するまで送信しません。` | 送信停止。人間回答後、正本反映と条件再確認を経て再開 | 準正常机上: 不明項目だけを示して止まる。異常: 推測で承認済み扱いにする |
| 範囲拡大 | 送信先、権限、対象path、外部送信、データ分類のいずれかが承認済み範囲を超える | `承認範囲外の変更があります。差分確認まで送信しません。` | 送信停止。人間回答後、正本反映と条件再確認を経て再開 | 準正常机上: 差分を表示して止まる。異常: 既存同意へ流用する |
| リスク受容 | 人間が残存リスク、制限、対象範囲を明示して受容した | `リスク受容済み範囲内です。制限を保持して続行します。` | 受容済み範囲だけ継続。未確認のボタン/取消コマンドやAuthorityは作らない | 正常机上: 受容範囲外は止まる。異常: 追加承認0だけで安全と表示する |
| 独立保留 | 同意再利用と独立した未解決事項、Graphic制作、理解時間、改善率、Runtime未実測が残る | `同意判定とは別の未確認事項があります。実行許可として扱いません。` | 本件送信判定とは分離して保留。雛形を実行許可にしない | 準正常机上: 保留が進行許可に変換されない。異常: 雛形だけで実行可能になる |

## 検証の分離

- 机上検証: 正常は初回承認と範囲内再利用、準正常は情報不足/範囲拡大/保留、異常は未承認送信・推測承認・同意流用を確認する。
- 実Runtime実測: 同一範囲で追加入力0回、範囲外/不明で送信停止、人間回答後の正本反映と条件再確認後の再開を測る。
- 追加承認0回は中断減少の観測値に限る。必要判断の見落とし、誤送信、未承認権限通過がないことを別に確認する。

## 残る確認

- 人間理解時間と改善率は未測定であり、必要なら別指標として取得する。
- UI文言はCLI短文案であり、Graphic、最終視覚表現、ボタン、取消コマンド、Authorityの新設は本受渡しに含めない。
- 下流では、表示案を実行許可ではなく、振る舞い仕様の停止/再開条件と対にして扱う。
