# 変更トレース: 初回レビュー・監査の網羅性

変更ID: `CHG-000003`
状態: `Released`
担当責任者: Qual-Lab
最終更新日: 2026-07-29

正本規則: [変更](../../12_Change.md)

## 契機 / 起点

- 種別: CRDD運用フィードバック
- 情報源: Qual-LabによるCRDD標準リポジトリの保守運用
- 問題: 親エージェントと監査の是正・再確認を繰り返すほど、初回から存在した別の問題が小出しに発見され、往復回数と見落としリスクが増える
- 既存規則: 複数監査の統合、修正後の再監査、新規指摘の分類は存在するが、各独立レビュー／監査が初回に適用観点を一度走査し終えてから報告する完了条件が弱い
- 人間による着手判断: 初回監査の網羅性をv0.11.2へ取り込み、安全上必要な停止と再レビューは維持する

## 主な変更意図

独立レビューと監査で、指摘候補の収集、水平探索、共通原因の整理を初回確認内で行い、初回から存在する問題の小出しを減らす。監査種別、恒久成果物、承認段階を増やさず、確認の順序と完了根拠を強化する。

## 想定する影響

- 共通エージェント契約: `10_Agent.md`
- 監査手順: `51_Document_Audit.md`、`52_Conformance_Audit.md`、`53_Gap_Impact_Audit.md`
- 準拠: エージェント型提供プロファイルへ`AD-21`を追加
- 公式／配布AI入口: `AGENTS.md`、`CLAUDE.md`、`.github/copilot-instructions.md`と`template/`内の対応ファイル
- 公開案内: `README.md`、`CHANGELOG.md`
- 利用側: レビュー／監査エージェントの指示更新が必要。既存のプロダクト成果物、フォルダ、安定コンテキストID、スキーマの変更は不要

## 対象外 / 変更してはならないこと

- 一回のレビューで問題が存在しないことを保証しない
- 修正後の再レビューを省略しない
- 安全、セキュリティ、プライバシー、法務、不可逆な損失等の停止・上位判断への移送を遅らせない
- 無制限なリポジトリ探索や、すべての変更への全監査を要求しない
- 新しい監査種別、承認段階、固定ファイル、固定スキーマ、安定コンテキストIDを追加しない
- 過去のCHANGELOGまたは公開済みタグを書き換えない

## 変更影響の伝播確認

- 変更する規範: 独立レビュー／監査の初回確認、是正引き渡し、再レビュー分類、エージェント型提供プロファイル
- 変更しない規範: 監査種別、決定権限、工程、成果物構造、安定コンテキストID
- 必要な確認: 全体機械確認、独立レビュー、文書監査、準拠監査、不足／影響監査
- 主な確認観点: 既存の監査統合規則との重複、停止条件の保持、軽量運用への影響、配布AI入口への伝播、AD-21追加による準拠影響
