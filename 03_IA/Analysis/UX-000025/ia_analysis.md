# IA分析: 過去の推論情報と現在値を区別する

成果物種別: IA分析
分析対象: [UX-000025](../../../02_UX/Definitions/UX-000025/ux_definition.md)
状態: 分析済み

## 1. UXから受け取る意味

| 観点 | この分析で受け取る内容 |
|---|---|
| 利用者 | CRDD作成者・保守者 |
| 場面 | 過去判断を再利用または更新する時 |
| 目的 | 当時の仮説と現在有効な意図を区別する |
| 得たい結果 | 判断理由を追跡しつつ古い前提を現在値にしない |
| 重要場面 | 判断理由をAIへ渡す場面 |
| 避ける失敗 | 履歴を上書きし競合する理由を勝手に統合する |
| 守る品質 | 現行性・選択範囲・使用改訂版を追跡する |

画面、API、保存形式は決めず、上記の利用者成果を情報の単位と関係へ変換する。

## 2. 情報候補と関係

| 候補 | 利用者にとっての意味 | 識別・関係 |
|---|---|---|
| 見分ける対象 | 推論の背景（Reasoning Context）、過去値（Historical Value）、現在有効な意図（Current Intent）、選択理由（Selection Reason）、改訂版（Revision） | 対象を同一視せず、「現在の仕事→選択した情報→根拠→過去値比較」の順に関係付ける。識別できない対象は既知の対象へ推定統合しない。 |
| 根拠と次の行動 | 現在の仕事→選択した情報→根拠→過去値比較 | 起点、判断対象、根拠、戻り先を同じ流れとして辿れるようにする。 |

```text
[O: CRDD作成者・保守者の判断] --確認する--> [O: 推論の背景（Reasoning Context）]
[O: 推論の背景（Reasoning Context）] --根拠と次の行動を辿る--> [O: 判断理由を追跡しつつ古い前提を現在値にしない]
```

## 3. 状態・可視性・導線・責任

| 観点 | 分析結果 |
|---|---|
| 状態 | 現在有効（current）／履歴（historical）／置換済み（superseded）／不明（unknown） |
| 可視性 | 判断理由をAIへ渡す場面では、現行性・選択範囲・使用改訂版を追跡するために必要な状態と不足を判断対象と同じ文脈で示す。詳細な識別情報と根拠は必要時に辿れるようにし、非開示対象は存在自体を推測表示しない。 |
| 導線 | 現在の仕事→選択した情報→根拠→過去値比較。結果がない、判断待ち、または状態不明の場合も、根拠か安全な戻り先を失わない。 |
| 責任 | CRDD作成者・保守者は「当時の仮説と現在有効な意図を区別する」ために必要な判断を行う。システムは「判断理由を追跡しつつ古い前提を現在値にしない」を支える対象・状態・根拠を示し、「履歴を上書きし競合する理由を勝手に統合する」という誤認を生まない責任を持つ。 |

## 4. 現行文書・実装との照合

| 照合対象 | 結果 |
|---|---|
| UXから導いた意味 | 対象・状態・導線は前節までを正とする。 |
| 現行構造 | 文書・履歴境界を利用できる。履歴確定識別子（Commit SHA）を唯一の成立条件にしない。 |
| 採用境界 | 現行の名称や状態値は、UX由来の意味と一致する範囲だけを照合根拠にする。実装にだけ存在する区分はIA定義へ逆流させない。 |

## 5. IA処置

[IA-000021](../../Definitions/IA-000021/ia_definition.md)へ接続する。情報の引き渡しではなく、過去の判断と現在有効な意図を区別するため、IA-000014へ統合しない。試作上の理解しやすさは未確認として下流へ渡す。
