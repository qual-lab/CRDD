# IA分析: 監査・是正・判断を一つの改訂版で閉じる

成果物種別: IA分析
分析対象: [UX-000023](../../../02_UX/Definitions/UX-000023/ux_definition.md)
状態: 分析済み

## 1. UXから受け取る意味

| 観点 | この分析で受け取る内容 |
|---|---|
| 利用者 | CRDD作成者・保守者 |
| 場面 | 複数指摘を是正する時 |
| 目的 | 監査合意から是正・反証までを一つの改訂版で閉じる |
| 得たい結果 | 小出しの指摘と局所PatchのLoopを減らせる |
| 重要場面 | 再レビューへ固定候補を渡す直前 |
| 避ける失敗 | 一部是正や監査回数を完成と誤認する |
| 守る品質 | 合意事項と試験を全数対応させる |

画面、API、保存形式は決めず、上記の利用者成果を情報の単位と関係へ変換する。

## 2. 情報候補と関係

| 候補 | 利用者にとっての意味 | 識別・関係 |
|---|---|---|
| 見分ける対象 | 改訂版（Revision）、指摘（Finding）、是正（Remediation）、Verification、判断依頼（Decision Request）、監査の組合せ（Audit Set） | 対象を同一視せず、「固定版→監査集合→統合方針→是正→再固定→判断」の順に関係付ける。識別できない対象は既知の対象へ推定統合しない。 |
| 根拠と次の行動 | 固定版→監査集合→統合方針→是正→再固定→判断 | 起点、判断対象、根拠、戻り先を同じ流れとして辿れるようにする。 |

```text
[O: CRDD作成者・保守者の判断] --確認する--> [O: 改訂版（Revision）]
[O: 改訂版（Revision）] --根拠と次の行動を辿る--> [O: 小出しの指摘と局所PatchのLoopを減らせる]
```

## 3. 状態・可視性・導線・責任

| 観点 | 分析結果 |
|---|---|
| 状態 | 固定済み（fixed）／レビュー中（under_review）／是正必要（changes_required）／確認済み（verified）／判断必要（decision_required） |
| 可視性 | 再レビューへ固定候補を渡す直前では、合意事項と試験を全数対応させるために必要な状態と不足を判断対象と同じ文脈で示す。詳細な識別情報と根拠は必要時に辿れるようにし、非開示対象は存在自体を推測表示しない。 |
| 導線 | 固定版→監査集合→統合方針→是正→再固定→判断。結果がない、判断待ち、または状態不明の場合も、根拠か安全な戻り先を失わない。 |
| 責任 | CRDD作成者・保守者は「監査合意から是正・反証までを一つの改訂版で閉じる」ために必要な判断を行う。システムは「小出しの指摘と局所PatchのLoopを減らせる」を支える対象・状態・根拠を示し、「一部是正や監査回数を完成と誤認する」という誤認を生まない責任を持つ。 |

## 4. 現行文書・実装との照合

| 照合対象 | 結果 |
|---|---|
| UXから導いた意味 | 対象・状態・導線は前節までを正とする。 |
| 現行構造 | CHGとQualityが根拠を保持する。別改訂版の結果を混在させない。 |
| 採用境界 | 現行の名称や状態値は、UX由来の意味と一致する範囲だけを照合根拠にする。実装にだけ存在する区分はIA定義へ逆流させない。 |

## 5. IA処置

[IA-000016](../../Definitions/IA-000016/ia_definition.md)へ接続する。上記7軸を接続先へ保持し、複数UXを統合する場合も対象固有の状態、失敗、導線を消さない。試作上の理解しやすさは未確認として下流へ渡す。
