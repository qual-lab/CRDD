# IA分析: 公式素材を権利と用途を確認して使う

成果物種別: IA分析
分析対象: [UX-000030](../../../02_UX/Definitions/UX-000030/ux_definition.md)
状態: 分析済み

## 1. UXから受け取る意味

| 観点 | この分析で受け取る内容 |
|---|---|
| 利用者 | CRDD作成者・保守者 |
| 場面 | ブランド素材を追加または利用する時 |
| 目的 | 視覚素材の出所・権利・用途を確認する |
| 得たい結果 | 公式識別へ安心して収載・派生利用できる |
| 重要場面 | 公式用途へ採用する直前 |
| 避ける失敗 | 見た目だけで権利や信頼保証を推定する |
| 守る品質 | 由来・権利・用途を追跡する |

画面、API、保存形式は決めず、上記の利用者成果を情報の単位と関係へ変換する。

## 2. 情報候補と関係

| 候補 | 利用者にとっての意味 | 識別・関係 |
|---|---|---|
| 見分ける対象 | 素材（Asset）、情報源（Source）、権利確認（Rights Statement）、許可用途（Allowed Use）、派生物（Derivative） | 対象を同一視せず、「素材→由来→権利→用途→収載・派生」の順に関係付ける。識別できない対象は既知の対象へ推定統合しない。 |
| 根拠と次の行動 | 素材→由来→権利→用途→収載・派生 | 起点、判断対象、根拠、戻り先を同じ流れとして辿れるようにする。 |

```text
[O: CRDD作成者・保守者の判断] --確認する--> [O: 素材（Asset）]
[O: 素材（Asset）] --根拠と次の行動を辿る--> [O: 公式識別へ安心して収載・派生利用できる]
```

## 3. 状態・可視性・導線・責任

| 観点 | 分析結果 |
|---|---|
| 状態 | 候補（candidate）／採用済み（approved）／開示制限（restricted）／取下げ済み（withdrawn） |
| 可視性 | 公式用途へ採用する直前では、由来・権利・用途を追跡するために必要な状態と不足を判断対象と同じ文脈で示す。詳細な識別情報と根拠は必要時に辿れるようにし、非開示対象は存在自体を推測表示しない。 |
| 導線 | 素材→由来→権利→用途→収載・派生。結果がない、判断待ち、または状態不明の場合も、根拠か安全な戻り先を失わない。 |
| 責任 | CRDD作成者・保守者は「視覚素材の出所・権利・用途を確認する」ために必要な判断を行う。システムは「公式識別へ安心して収載・派生利用できる」を支える対象・状態・根拠を示し、「見た目だけで権利や信頼保証を推定する」という誤認を生まない責任を持つ。 |

## 4. 現行文書・実装との照合

| 照合対象 | 結果 |
|---|---|
| UXから導いた意味 | 対象・状態・導線は前節までを正とする。 |
| 現行構造 | CommunicationとReleaseに記録がある。見た目の公式性を権利根拠にしない。 |
| 採用境界 | 現行の名称や状態値は、UX由来の意味と一致する範囲だけを照合根拠にする。実装にだけ存在する区分はIA定義へ逆流させない。 |

## 5. IA処置

[IA-000019](../../Definitions/IA-000019/ia_definition.md)へ接続する。上記7軸を接続先へ保持し、複数UXを統合する場合も対象固有の状態、失敗、導線を消さない。試作上の理解しやすさは未確認として下流へ渡す。
