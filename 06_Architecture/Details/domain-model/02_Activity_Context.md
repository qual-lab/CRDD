# 旧活動Context設計の退役案内

状態: Retired（v0.22 Feature）
最終更新日: 2026-11-17

現在の正本は[文書モデル](../document-model/01_Architecture.md)と[活動Context](../document-model/02_Activity_Context.md)である。本書に旧設計本文・転送見出し一覧・旧APIを残さない。

Topic／Meetingの意味・改訂・保存は文書モデル、現在認可は[Access Management](../access-management/01_Architecture.md)、実行調停は[Coordinator](../coordinator/01_Architecture.md)が所有する。旧DomainやCROSの認証・実行Authorityを活動モデルへまとめない。

保存先は現在Ownerの契約に従い、この整理では変更しない。当時の設計・検証はGit履歴と[既存変更計画](../../../99_Roadmap/Changes/CHG-000082/domain-model-three-package-plan.md)で追跡する。未接続・未評価を完了へ変えない。
