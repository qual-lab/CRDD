# 変更トレース: 着手前整合確認

変更トレースID: `CHG-000006`
状態: `Released`
担当責任者: Qual-Lab
最終更新日: 2026-07-31

正本規則: [変更](../../12_Change.md)

## 契機 / 起点

CRDDの運用で、完成後の独立レビューや監査が同じ対象を複数回往復し、後の回で影響先、専門観点、用語または表現の不整合が追加発見される事象があった。

現行CRDDには、作業開始時の計画提示、変更分類、経路選択、完成後の初回レビュー網羅性、複数監査の統合がある。一方、提示した計画を現在の正本、参照関係、派生成果物、必要な専門観点、用語・表現へ照合し、その結果を初回編集前に計画へ統合する時点契約がなかった。

## 保持する意図

- 監査で後から判明する計画上の見落としを、可能な範囲で初回編集前に減らす
- 小さな案件や局所変更へ確認者、承認、成果物を機械的に増やさない
- 正式監査、完成後レビュー、人間の決定権限を前倒し確認で代替しない
- 特定AI、サブエージェント、固定ツールへ依存しない
- 人間向けの表現とAIが参照する正式用語の両方を維持する

## 対象外 / 変更してはならないこと

- 新しい監査文書、恒久成果物、専用フォルダ、安定コンテキストIDを作らない
- すべての変更へ専門家、サブエージェント、複数確認者を要求しない
- 着手前の結果を`Pass`、採用、実行許可、リスク受容または完成判定として扱わない
- 工程固有の入口、網羅範囲、出口をエージェント文書へ移さない
- 既存の境界付き修正提案や監査間是正方針レビューと同じ確認を重複実行しない

## 変更分類と移行

- 変更分類: `normative`
- 理由: 非自明な変更に対するAIの初回編集前の必須行動と、Agentic Delivery基準`AD-02`の根拠を変更する
- リリースレベル: `MINOR`
- 対象バージョン: `v0.12.0`
- `migration_required`: `true`
- 移行対象: AIを使用して非自明な変更を行う採用プロジェクトのAI入口または同等の作業手順

移行では、同等の着手前確認があるかを確認し、なければ新しい基準への参照または短い実行指示を追加する。プロダクト成果物、フォルダ、安定コンテキストID、完了済み工程または過去の変更トレースの書換えは要求しない。

## 着手前レビュー

初回編集前に、次の読み取り専用観点を確認した。

| 観点 | 結果 |
|---|---|
| 影響・不足 | 計画提示と完成後監査の間に、現在の関係を軽量走査して計画へ戻す時点契約が不足 |
| エージェント運用 | 親エージェントの軽量確認を基本とし、不足する専門観点だけを読み取り専用で委譲する構造を推奨 |
| 用語・可読性 | 当初は規則名として扱う案だったが、固有結果と`AD-02`の判定条件を持つ完成案では正式用語の登録条件に該当すると判明 |

統合方針:

- 「着手前整合確認（Pre-execution Alignment Check）」を用語集の補助概念へ登録し、詳細な実行規則はエージェント文書を正本とする
- 親エージェントが現在の正本と計画を照合する
- 必要な専門観点を親エージェントだけでは確認できない場合、または計画の誤りが複数正本、複数工程、決定権限、移行、重大リスクへ波及し得る場合だけ、不足する専門観点を別の確認者へ渡す
- 確認者の結果は`着手可`、`計画修正`、`判断待ち・停止`とし、完成物の監査状態と区別する
- 用語・表現では、既存用語、主要ロケールの表示名、対象読者、曖昧語、意味差を編集前に確認する
- 完成後は新しい改訂版を対象に独立レビューと必要な監査を実行する

## 検証計画

- CRDD全体Checkerによるリンク、アンカー、版、構造の確認
- 文書監査による正本配置、重複、用語、可読性、AI入口の確認
- 不足／影響監査による採用側、準拠、移行、工程への影響確認
- 準拠監査による`AD-02`と変更分類・移行要否の確認
- エージェント運用の独立レビューによる軽量条件、委譲、完成後確認との境界確認

## 実際の影響 / 逸脱

- 当初の用語・可読性レビューでは着手前整合確認を規則名として扱う案だった
- 完成版の文書監査で、固有の結果集合と`AD-02`の判定条件を持つため正式用語の登録条件に該当すると確認され、補助概念として用語集へ登録する方針へ変更した
- 着手前整合確認を独立したスキル手順として追加すると既存の`current_step`と不整合になるため、`AssessGap`で表す再評価活動へ修正した
- Agentic Deliveryの`AD-02`へ影響するが、Core、Product Lifecycle、工程成果物、フォルダ、安定コンテキストID、プロダクト実装には影響しない
- 想定外の監査種別、承認、恒久成果物またはツール依存は追加していない

## 正本コンテキストの更新

- エージェント文書を着手前整合確認の実行規則の正本とした
- 用語集へ表示名、正式英語名、3結果、近い概念との境界を追加した
- 文書化へ、用語・表現を編集前に確認する条件と観点を追加した
- スキルでは新しい状態値を作らず、計画具体化後に`AssessGap`へ再び移る活動として接続した
- 保守ライフサイクル、変更経路案内、Agentic Deliveryの`AD-02`、正式な不足／影響監査との境界を更新した
- Root／TemplateのAI入口を、全非自明変更での親エージェントによる軽量照合と、条件付きの専門観点委譲へ揃えた

## 既知制限 / 残存リスク

- 実プロジェクトで監査往復回数や作業時間がどの程度減るかは未計測
- AIまたはモデルごとの指示追従率は保証しない
- 着手前整合確認は完成前の計画を評価するため、完成物固有の欠陥を検出できない
- 採用側での移行結果は未確定
