# UX-000026 試験層と現在の保証範囲を理解して選ぶ

成果物種別: UX定義
UX ID: `UX-000026`
状態: Canonical
維持責任者: Qual-Lab

## 利用者成果

各試験層が確認したこと・未確認範囲・時間や費用を理解し、必要な検証と高負荷試験の実行有無を選べる

```text
CRDD作成者・保守者
        │ 変更の検証計画を作る時
        ▼
試験層ごとの保証と未確認範囲を理解する
        │
        ▼
最終E2E前に外部境界の問題を局所化できる
```

## 利用者に起きる変化

```text
変更前
────────────────
- UT・IT・E2Eを区別せず繰り返し、失敗原因と残る不確実性が分からない
        │
        │ 段階的実境界試験と回帰選択が変える体験
        ▼
変更後
────────────────
- どの成立条件をどの試験で確認し、何が未確認か理解して次の検証を選べる
```

段階的実境界試験と回帰選択は、単に内部方式を成立させる要求ではない。「UT・IT・E2Eを区別せず繰り返し、失敗原因と残る不確実性が分からない」状態から、「どの成立条件をどの試験で確認し、何が未確認か理解して次の検証を選べる」状態へ変わり、利用者が次の判断へ進めることまでを体験として扱う。

実装者・品質確認者が試験層ごとの保証と未確認範囲を理解することで、最終E2E前に外部境界の問題を局所化できるようになることを守る。

## 成立条件

- 各試験層が確認したこと・未確認範囲・時間や費用を理解し、必要な検証と高負荷試験の実行有無を選べる
- 重要場面「外部境界を結合する各段階」で、避ける失敗を利用者が正常状態や完了として誤認しない。
- 入口、実装または利用主体が変わっても、この利用者成果の意味を維持する。

## 重要な体験・失敗・品質期待

```text
変更の検証計画を作る時
        ↓
試験層ごとの保証と未確認範囲を理解する
        │
        ├─ ★ 重要場面: 外部境界を結合する各段階
        ├─ ⚠ 失敗:  単発成功や試験件数から一連の状態変化全体を保証する
        └─ ✓ 守る品質:  開始から清掃まで段階的に反証する
        ↓
最終E2E前に外部境界の問題を局所化できる
```

### 重要な失敗

- 単発成功や試験件数から一連の状態変化全体を保証する

### 体験品質への期待

- 開始から清掃まで段階的に反証する

## 必要な情報

Test Layer、対象範囲、一連の状態変化 根拠、決定権限、Not Executed Stateを結ぶ

## 責任境界・制約・対象外

- UXが定義すること: 利用者、状況、目的、得られる結果、重要場面、失敗および品質期待。
- 下流工程へ残すこと: 情報構造、表示、操作、振る舞いおよび実現方式。
- 対象外: 特定画面、通信方式、内部構成、試験段階または実装方式の決定。

- 画面、通信方式、内部構成要素または特定の実装方式をUX成果そのものにしない。
- 下流工程は利用者成果を弱めず、情報構造、操作、振る舞いおよび実現方式へ具体化する。
- 想定した利用者、状況または目的が誤っていると判明した場合は、元の要求分析とDiscoveryへ戻す。

## 未確認事項と戻り条件

未確認事項は、統合元の要求ごとに次を保持する。

- REQ-000030: CRDD作成者・保守者が「試験層ごとの保証と未確認範囲を理解する」を行う際の判断基準、許容負担、利用環境および失敗後の選択
- 現在判定: 後続の実利用確認が必要。現在のUX定義をCanonical化する判断を止める事項ではない。
- 確認事項: REQ-000030: CRDD作成者・保守者が「試験層ごとの保証と未確認範囲を理解する」を行う際の判断基準、許容負担、利用環境および失敗後の選択
- 判断者: CRDD作成者・保守者を代表する利用者とQual-Lab。
- 未確認時の影響: 利用者成果、重要場面、失敗および品質期待を仮説として保持し、定量条件や実現方式を確定しない。
- Discoveryへ戻す条件: 想定した利用者、問題、望ましい変化または制約が誤っていると判明した場合。
- UX分析へ戻す条件: 利用場面、目的、得られる結果、重要場面、失敗または品質期待の統合判断が変わる場合。

## 検証意図

一部Passからの全体品質推定、単発成功だけの一連の状態変化保証および未指示の高負荷実行を反証する

具体的な試験段階、試験場面、期待結果は検証（Verification）工程で設計し、この体験定義には実行結果を書き込まない。
