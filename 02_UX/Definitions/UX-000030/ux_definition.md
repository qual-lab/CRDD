# UX-000030 公式素材を権利と用途を確認して使う

成果物種別: UX定義
UX ID: `UX-000030`
状態: Canonical
維持責任者: Qual-Lab

## 利用者成果

公式素材の出所・原本・派生物・利用条件を確認し、許可された用途で安心して収載・再利用できる

```text
CRDD作成者・保守者
        │ ブランド素材を追加または利用する時
        ▼
視覚素材の出所・権利・用途を確認する
        │
        ▼
公式識別へ安心して収載・派生利用できる
```

## 利用者・状況・目的

| 項目 | 内容 |
|---|---|
| 主な想定利用者／利用状況 | [製品全体の利用者像](../../02_Personas.md)の「CRDD作成者・保守者」 |
| 利用のきっかけ／場面 | ブランド素材を追加または利用する時 |
| 目的 | 視覚素材の出所・権利・用途を確認する |
| 得られる結果 | 公式識別へ安心して収載・派生利用できる |

## 利用者に起きる変化

```text
変更前
────────────────
- 保守者が素材の見た目だけから、原本、権利、許可用途および派生関係を推測する
        │
        │ 公式素材を安全に収載・再利用できる体験
        ▼
変更後
────────────────
- 保守者が素材の出所、原本、権利、許可用途および派生関係を確認し、収載・変更・再利用の可否を判断できる
```

この変化が扱うのは、素材を収載・変更・再利用する保守者の体験である。見た目ではなく、出所、原本、権利、許可用途および派生関係を根拠に扱い方を決められることを守る。閲覧者が公式入口を見分ける体験は`UX-000031`が所有する。

## 成立条件

- 公式素材の出所・原本・派生物・利用条件を確認し、許可された用途で安心して収載・再利用できる
- 重要場面「公式用途へ採用する直前」で、避ける失敗を利用者が正常状態や完了として誤認しない。
- 入口、実装または利用主体が変わっても、この利用者成果の意味を維持する。

## 重要な体験・失敗・品質期待

```text
ブランド素材を追加または利用する時
        ↓
視覚素材の出所・権利・用途を確認する
        │
        ├─ ★ 重要場面: 公式用途へ採用する直前
        ├─ ⚠ 失敗:  見た目だけで権利や信頼保証を推定する
        └─ ✓ 守る品質:  由来・権利・用途を追跡する
        ↓
公式識別へ安心して収載・派生利用できる
```

### 重要な失敗

- 見た目だけで権利や信頼保証を推定する

### 体験品質への期待

- 由来・権利・用途を追跡する

## 必要な情報

素材、由来、権利、用途を結ぶ

## 責任境界・制約・対象外

- UXが定義すること: 利用者、状況、目的、得られる結果、重要場面、失敗および品質期待。
- 下流工程へ残すこと: 情報構造、表示、操作、振る舞いおよび実現方式。
- 対象外: 特定画面、通信方式、内部構成、試験段階または実装方式の決定。

- 画面、通信方式、内部構成要素または特定の実装方式をUX成果そのものにしない。
- 下流工程は利用者成果を弱めず、情報構造、操作、振る舞いおよび実現方式へ具体化する。
- 想定した利用者、状況または目的が誤っていると判明した場合は、元の要求分析とDiscoveryへ戻す。

## 未確認事項と戻り条件

未確認事項は、統合元の要求ごとに次を保持する。

- REQ-000035: 識別表示が入口発見を助けながら信頼誤認を増やさないか、権利情報の許容確認負担
- 現在判定: 後続の実利用確認が必要。現在のUX定義をCanonical化する判断を止める事項ではない。
- 確認事項: REQ-000035: 識別表示が入口発見を助けながら信頼誤認を増やさないか、権利情報の許容確認負担
- 判断者: CRDD作成者・保守者を代表する利用者とQual-Lab。
- 未確認時の影響: 利用者成果、重要場面、失敗および品質期待を仮説として保持し、定量条件や実現方式を確定しない。
- Discoveryへ戻す条件: 想定した利用者、問題、望ましい変化または制約が誤っていると判明した場合。
- UX分析へ戻す条件: 利用場面、目的、得られる結果、重要場面、失敗または品質期待の統合判断が変わる場合。

## 検証意図

見た目からの信頼保証推定、権利不明素材の収載および用途外再配布を反証する

具体的な試験段階、試験場面、期待結果は検証（Verification）工程で設計し、この体験定義には実行結果を書き込まない。
