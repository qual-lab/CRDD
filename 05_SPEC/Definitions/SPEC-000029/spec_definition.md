# SPEC-000029 判断待ちTaskへの判断返却

成果物種別: SPEC定義
SPEC ID: `SPEC-000029`
状態: Canonical
維持責任者: Qual-Lab

## 振る舞いの目的

判断待ちの同じTaskへ、許可された人間の判断または追加入力を返し、そのTaskを再開可能にする。

## UX観点の入力

| UX分析 | 保持する利用者成果 |
|---|---|
| [UX-000003](../../Analysis/UX-000003/spec_analysis.md) | 委任中の状態と判断要否を理解し、求められた判断を返せる |

## IA観点の入力

| IA分析 | 保持する情報構造 |
|---|---|
| [IA-000002](../../Analysis/IA-000002/spec_analysis.md) | Task、判断対象、決定権限、入力、現在状態および次の行動 |

## 両観点の統合判断

Taskが人間の判断または追加入力を待つ時、同じRequest、Task、判断点および現在世代を検証する。許可された判断だけを一度記録し、同じTaskの再開へ結ぶ。

## 契機・事前条件・Authority

| 項目 | 契約 |
|---|---|
| 契機 | Taskが特定の人間判断または追加入力を待ち、利用者が回答する時 |
| 事前条件 | Request、Task、判断点、現在世代、許可された選択肢または入力形式を確認できる |
| Authority | その判断点へ結合した人間の決定権限。委任範囲、Provider実行、取消、回復または別判断点の権限を含まない |
| 判定不能 | 判断を記録せず、Taskを再開せず、現在の判断待ち状態と再確認先を保持する |

## 振る舞い・状態・結果

```text
[判断待ち]
    │ --Task・判断点・世代・決定権限を検証-->
    ▼
[判断記録済み] --同じTaskへ結合--> [再開可能]
    │                                  │
    └--競合／重複--> [blocked]         └--Runtimeが再開--> [実行中／結果]
```

- 振る舞い: 許可された判断または追加入力をexactな判断点へ一度記録し、同じTaskの再開条件を成立させる。
- 成功条件: 記録した判断、対象Task、判断点、現在世代および次状態を一意に確認できる。
- 判断の記録とTaskの実行再開を分け、判断返却だけからProvider作用の開始を推定しない。

## 失敗・回復・副作用

- 失敗: 古い世代、別Task、別判断点、許可外の選択肢、権限不一致または既に処置済みの判断はEffect 0で拒否する。
- 副作用: 検証済みの判断点へ判断または入力を一度記録し、同じTaskへ再開可能通知を一度だけ渡す。新しいTaskや試行は自動作成しない。
- 記録後に再開結果を観測できない場合は、判断を重複記録せず同じTaskの状態照会または回復へ戻す。

## 受入条件と検証義務

| 観点 | 受入条件 |
|---|---|
| 正常 | exactな判断点へ許可された判断を記録し、同じTaskを再開可能にする |
| 境界 | Task／判断点／世代／決定権限の一致と不一致を分け、別対象へ判断を適用しない |
| 競合 | 同じ判断の再送、異なる判断の競合および既に完了したTaskを区別し、最初の確定結果を上書きしない |
| 失敗 | 許可外入力や古い判断をEffect 0で拒否し、判断待ち状態を保持する |
| 観測不能 | 判断記録済みか不明な時に重複記録または新規Task作成を行わない |
| 対応UI | [UI-000002](../../../04_UI/Definitions/UI-000002/ui_definition.md)の判断返却、状態表示および次の行動と一致する |

## 制約

API、Process、保存方式、画面、部品または実装技術を本定義で確定しない。判断返却を委任、取消、回復または採用判断へ流用しない。
