# UX-000030のSPEC分析

成果物種別: SPEC分析（UX観点）
分析単位: `UX-000030`
状態: 分析済み

## 1. 正式入力

- UX定義: [UX-000030 公式素材を権利と用途を確認して使う](../../../02_UX/Definitions/UX-000030/ux_definition.md)

IA、UIまたはREQを直接読んで不足を補完しない。この分析はUX定義から、利用者に観測できる振る舞いと失敗だけを導く。

## 2. 振る舞いへ引き継ぐ利用者成果

公式素材の出所・原本・派生物・利用条件を確認し、許可された用途で安心して収載・再利用できる

| 観点 | UX定義から受け取る内容 |
|---|---|
| 利用者／状況 | [製品全体の利用者像](../../../02_UX/02_Personas.md)の「CRDD作成者・保守者」 |
| 利用のきっかけ | ブランド素材を追加または利用する時 |
| 目的 | 視覚素材の出所・権利・用途を確認する |
| 利用者成果 | 公式素材の出所・原本・派生物・利用条件を確認し、許可された用途で安心して収載・再利用できる |
| 必要な情報 | 素材、由来、権利、用途を結ぶ |
| 重要場面 | 公式用途へ採用する直前 |
| 避ける失敗 | 見た目だけで権利や信頼保証を推定する |
| 守る品質 | 由来・権利・用途を追跡する |
| 検証意図 | 見た目からの信頼保証推定、権利不明素材の収載および用途外再配布を反証する |

## 3. 観測可能にする契機・結果・失敗

```text
[製品全体の利用者像](../../../02_UX/02_Personas.md)の「CRDD作成者・保守者」
        │ ブランド素材を追加または利用する時
        ▼
視覚素材の出所・権利・用途を確認する
        │
        ├─ 成立   → 公式素材の出所・原本・派生物・利用条件を確認し、許可された用途で安心して収載・再利用できる
        ├─ 不成立 → 見た目だけで権利や信頼保証を推定する
        └─ 不明   → 推測せず不足情報または再確認先
```

- ★ 判断点: 公式用途へ採用する直前
- 成功は処理の開始ではなく、「由来・権利・用途を追跡する」を守って利用者成果を観測できる結果で判定する。
- UXが要求しない取消、回復、Authorityまたは外部Effectをひな型だけから追加しない。

## 4. 受入条件と適用範囲

- 正常: 公式素材の出所・原本・派生物・利用条件を確認し、許可された用途で安心して収載・再利用できる
- 失敗: 見た目だけで権利や信頼保証を推定する
- 品質: 由来・権利・用途を追跡する
- 判断不能: 不足を補完せず、何を再確認すべきかを返す。
- 下流へは「Communicationは識別用途と表示を、Releaseは権利・原本・派生物の追跡を具体化する。」を失わず渡す。
