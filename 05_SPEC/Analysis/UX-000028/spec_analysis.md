## 1. 正式入力

- UX定義: [UX-000028 工程固有の図から意図を引き継ぐ](../../../02_UX/Definitions/UX-000028/ux_definition.md)

IA、UIまたはREQを直接読んで不足を補完しない。この分析はUX定義から、利用者に観測できる振る舞いと失敗だけを導く。

## 2. 振る舞いへ引き継ぐ利用者成果

工程固有の図から全体像・関係・状態差・未接続を理解し、後工程で意図を再発明せずに引き継げる

| 利用のきっかけ | 工程の入口・出口で成果物を渡す時 |

| 必要な情報 | Diagram Element、情報源が持つ意味、引き渡す義務を結ぶ |
| 重要場面 | 下流義務へ変換する場面 |

## 3. 観測可能にする契機・結果・失敗

```text
[製品全体の利用者像](../../../02_UX/02_Personas.md)の「CRDD閲覧者」。設計・実装・検証を引き継ぐ後工程担当者を含む
        │ 工程の入口・出口で成果物を渡す時
        ▼
工程固有の図から状態・関係・未接続を理解する
        │
        ├─ 成立   → 工程固有の図から全体像・関係・状態差・未接続を理解し、後工程で意図を再発明せずに引き継げる
        ├─ 不成立 → 必要な図を黙って省略しAIごとに記法が変わる
        └─ 不明   → 推測せず不足情報または再確認先
```

- ★ 判断点: 下流義務へ変換する場面
- 成功は処理の開始ではなく、「図の意味・凡例・正本関係を固定する」を守って利用者成果を観測できる結果で判定する。
- UXが要求しない取消、回復、Authorityまたは外部Effectをひな型だけから追加しない。

## 4. 受入条件と適用範囲

- 正常: 工程固有の図から全体像・関係・状態差・未接続を理解し、後工程で意図を再発明せずに引き継げる
- 失敗: 必要な図を黙って省略しAIごとに記法が変わる
- 品質: 図の意味・凡例・正本関係を固定する
- 判断不能: 不足を補完せず、何を再確認すべきかを返す。
- 下流へは「各工程は図の意味と処置を所有し、Checkerは欠落を、レビューは意味の正しさを確認する。」を失わず渡す。
