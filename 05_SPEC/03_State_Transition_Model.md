# 状態遷移

## 1. 共通状態の意味

| 状態 | 入口条件 | 許される行動 | 出口条件 |
|---|---|---|---|
| ready | 対象・入力・Authorityを検証済み | 実行、取消 | Effect開始または安全な拒否 |
| running | 処理開始を観測 | 状態照会、適用時だけ取消 | 結果、失敗、判断待ち |
| waiting | 人間判断または外部条件待ち | 入力、取消、状態照会 | 条件充足または停止 |
| blocked | 継続条件を満たさない | 理由確認、適用時だけ回復 | 条件解消またはsettled |
| completed | 成功条件と結果を観測 | 結果取得 | settled |
| failed | 失敗と保持状態を観測 | 状態確認、適用時だけ回復／再試行 | blocked、completed、settled |
| settled | Effect・資源・義務の終了後を確認 | 新しい依頼 | 新規Taskのみ |

状態を持たない読取り・文書検査へこの全Lifecycleを強制しない。各SPEC定義の適用条件を正とする。

## 2. 回復義務

```text
[義務なし]
    │ effect不明／残存を観測
    ▼
[義務あり・未処置] --処置開始--> [処置中]
                                     │ 処置終了
                                     ▼
                         [処置済み・終了後未確認]
                                     │ 不存在／安全終了を再観測
                                     ▼
                                [義務解消]
```
