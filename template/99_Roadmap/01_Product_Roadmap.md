# プロダクトロードマップ（Product Roadmap）

決定権限: `00_CRDD/21_Discovery.md` 節 6, `01_Discovery` と `99_Roadmap`

本書はプロジェクト固有の未完了作業の登録簿（Open Work Registry）の主要表示であり、CRDD規範の正本ではない。登録対象と登録義務、項目契約、決定権限、判断状態と対応状態、主要 / 詳細、着手、完了、整理は上記正本に従う。

本書は索引である。項目の意味、根拠、判断理由、確定結果は責務を持つ正本成果物へ残し、ここへ複製しない。本書への参照行は登録の実現方式の一例である。変更トレース索引からの生成、外部の課題管理／進捗管理ツールからの投影、動的な集約で登録を満たしてもよい。本書へ登録されていることは、採用、優先順位の確定、実行の許可を意味しない。

プロジェクト固有のレビュー対象 / 再評価契機:

```text
未完了事項を認知
        ↓
登録簿へ登録（判断状態 / 対応状態）
        ↓
課題探索・要求形成による分析と人間の判断
  ├─ Exploring / Held → 再検討契機を保持
  ├─ Rejected / Superseded → 終了理由と判断参照
  └─ Adopted
        ↓
主要表示 ──→ 詳細ファイル（必要時のみ）
        ↓
開始条件 / 再評価契機
        ↓
Ready for Review / 人間による着手判断
  ├─ 再延期 / 取消
  └─ 開始 → CHG-* → 必要な工程 → 検証
                              ↓
                  正本と適用される結果へ反映
                              ↓
                    完了項目を主要表示から除去
                              ↓
                  詳細ファイルを使用した場合は削除
```

判断状態（Decision State）: `Unreviewed` / `Exploring` / `Held` / `Adopted` / `Rejected` / `Superseded`
（採否の判断を受ける項目にだけ適用する。変更トレース参照、明確な不具合、承認済み是正等の実行・参照項目には適用せず、対応状態と実行根拠への参照を保持する）

対応状態（Work State）: `Unscheduled` / `Ready for Review` / `Planned` / `In Progress` / `Completed` / `Cancelled`

依存、判断待ち、情報不足等による停止は対応状態の値にせず、停止要因として理由と解除条件を記録する。

### 成熟度に応じて追加する情報

| 成熟段階 | 追加する情報 | 空成果物を作らない条件 |
|---|---|---|
| 探索中 | 保持理由、再評価契機、判断所有者 | 根拠のない優先順位、期日、CHGは作らない |
| 採用・計画済み | 優先順位または対象時期、実行理由、開始条件 | 判断されていない日付や工数を補完しない |
| 実行中 | 開始CHG、依存、停止要因 | CHG未作成なら架空IDを置かない |
| 完了・終了 | 結果、検証参照、終了理由 | 結果未確認なら完了へ進めない |
