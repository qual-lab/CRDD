# 想定利用者

本書は要求別UX分析で確認した利用者像を製品全体で比較・統合する。年齢、趣味または架空の経歴を形式的に作らず、目的、困りごと、行動、判断、利用状況および必要な支援に意味のある差だけを表す。本書は個別要求分析の入力正本または代替ではなく、個別分析はその要求の利用者と状況を自己完結して示す。

## 未確認事項

確認していない利用頻度、能力差、環境差、一般化できない範囲および確認方法を示す。

## 補足（必要な場合）

上の節へ無理に入れると、利用者像の共通性や差が分かりにくくなる補足だけを書く。個別要求固有の分析を移さず、作業日誌や未分類のメモにも使わない。同じ種類の補足が繰り返される場合は標準項目への昇格を見直す。補足がなければ、この節は削除する。

## Checklist

ひな型では`[ ]`を未評価として残す。完成時は、処置済みを`[x]`、未完了を`OPEN: 理由 — 項目`、不適合を`FAIL: 理由 — 項目`、非該当を`N/A: 理由 — 項目`として評価する。

- [ ] 利用者像を個別UX分析から横断合成した
- [ ] 全UX IDの主要な利用者を処置した
- [ ] 役割と利用者の目的を混同していない
- [ ] 目的、困りごと、利用状況および判断責任に意味のある差で分けた
- [ ] 架空の属性、根拠のない能力差または役職だけで利用者像を作っていない
- [ ] 共通性と要求固有の差を混同していない
- [ ] 根拠、確信度および未確認範囲を示した
- [ ] 利用者分類をUIの権限設計へ先取りしていない
- [ ] 個別UX Definitionと矛盾していない
- [ ] 補足へ利用者一覧や必須の差を退避していない
