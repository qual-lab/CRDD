# 想定利用者

本書は製品全体の想定利用者を所有する。年齢、趣味または架空の経歴を形式的に作らず、目的、困りごと、行動、判断、利用状況および必要な支援に意味のある差だけを表す。個別要求では本書を参照し、その要求に固有の差だけを補足する。

## 想定利用者の関係図

```text
（利用者 A）          （利用者 B）
     │                    │
     ▼                    ▼
  （目的）              （目的）
     │                    │
     └──── 共通する仕事 ──┘
```

## 想定利用者ごとの物語

想定利用者ごとに、何をしている人が、どの状況で何に困り、何を達成したいかを短い物語と必要な図で示す。

## 未確認事項

確認していない利用頻度、能力差、環境差、一般化できない範囲および確認方法を示す。
