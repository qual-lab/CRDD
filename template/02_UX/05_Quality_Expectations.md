# 体験品質として守ること

本書は各要求で見つかった体験品質への期待を製品全体で統合する。数値条件や実現方式を定めず、人または運用者にどう現れる必要があるかを所有する。

## 品質期待の全体像

```text
理解できる ─┐
辿れる ─────┼→ 安心して次の判断へ進める
回復できる ─┤
待たされない ┘
```

|---|---|---|---|---|
| | | | | |

## 競合・優先順位・未確認事項

速度と根拠確認、簡潔さと不完全性表示等の両立が難しい点、現在の優先判断、未確認の許容範囲を示す。
