本書はUX工程の固定入口である。製品全体で目指す体験、現在有効なUX成果、要求の網羅状況、詳細成果物への案内を所有する。想定利用者、利用体験の全体像、サービス提供の流れおよび品質期待の詳細を複製しない。

```text
Discoveryで採用した要求（REQ-*）
      ↓ 個別分析
要求別の利用体験分析（Analysis/<REQ-ID>/ux_analysis.md）
      ↓ 既存UXへ統合するか新しいUXにするかを判断
現在有効な利用者成果（Definitions/<UX-ID>/ux_definition.md）
      ↓
想定利用者・利用体験の全体像・サービス提供の流れ・品質期待
      ├─→ IA                     直後工程への正式な引き渡し
      ├─→ Quality Analysis / UX  UX工程に伴走
      └─→ UI / SPEC              IA完了後のContract Relation
                                  ↓
                               Architecture
```

## 7. 補足（必要な場合）

上の節へ無理に入れると、UX全体の理解や工程移行判断が分かりにくくなる補足だけを書く。個別分析・UX定義・横断成果物が所有する詳細を複製せず、作業日誌や未分類のメモにも使わない。同じ種類の補足が繰り返される場合は、固定入口または該当横断成果物の標準項目へ昇格するかを見直す。補足がなければ、この節は削除する。
