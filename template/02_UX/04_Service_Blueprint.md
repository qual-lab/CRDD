# Service Blueprint

本書は主要な利用体験を、人間、利用者接点、System／AI、運用および根拠の責任へ接続する。個別REQでは本書の該当区間を参照し、Blueprint全体を複製しない。

## Product Service Blueprint

```text
利用者        [目的を示す] ───→ [状態を理解] ───→ [判断する]
                         │                 │
----------------------- 可視境界 -----------------------
                         ▼                 ▼
接点           [入力を受ける] ───→ [結果を示す] ───→ [次の行動]
                         │                 │
System／AI      [許可を確認] ───→ [処理・投影] ───→ [記録・回復]
                         │                 │
運用・根拠       [正本／Evidence] ─→ [確認・支援] ───→ [改善へ戻す]
```

## 区間と責任境界

| 区間 | 利用者が経験すること | 支える責任 | 失敗・回復 | 関係UX／REQ |
|---|---|---|---|---|
| | | | | |

## 対象外・未確認事項

Blueprintで先取りしない実装方式と、実利用で確認する責任境界を示す。
