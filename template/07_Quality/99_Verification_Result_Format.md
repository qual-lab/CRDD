# 検証結果の記録形式（Verification Result Format）

本書は検証結果そのものではなく、ChangeまたはReleaseの`Evidence/`へ検証結果を作成するときの記録形式である。本書へ個別結果を追記せず、直接証明する対象の配下へ新しいEvidenceを作成する。

確定後は履歴として保持する。追加実行または再検証では新しい検証結果を作成し、以前の結果との関係を示す。

対象、条件、結果、根拠、未確認範囲および残るGateは表を優先する。実行手順や時系列を本文の主経路にせず、必要な詳細は根拠へ参照する。

## Checklist

結果は`[x]`、未評価は`[ ]`、未完了は`OPEN: 理由`、不適合は`FAIL: 理由`、非該当は`N/A: 理由`で記録する。

- [ ] 対象改訂版と実行条件を固定した
- [ ] 実際の結果と期待結果を区別した
- [ ] 検証項目結果と検証義務評価を接続した
- [ ] 未確認範囲と残存Riskを示した
- [ ] 適用関係、無効化条件および再検証条件を示した
- [ ] Quality Centerへの反映要否を評価した
- [ ] 保存するEvidenceと保存しない機密情報・生データを区別した
- [ ] 11項目の必須適用判断を全数処置した
- [ ] N/Aに理由を、OPENに理由・影響・確認先・再評価契機を記録した
- [ ] PT／LTを人間の指定なく実行していない
