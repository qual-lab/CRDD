## 検証意図

何を確認し、どの不確実性またはリスクを減らすかを記載する。

## 検証項目

| 参照 | 検証義務 | 検証方法 | 観測対象 | 必要な根拠 | 専門性／独立性 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

テストケース、専門家レビュー、利用者評価、計測、分析、静的解析、視覚品質レビュー、アクセシビリティ監査等を対象に応じて使用する。

短い対象範囲では、参照欄に説明的な名称、パスまたはアンカーを使用してよい。同じ検証項目を複数の検証結果や成果物から繰り返し参照する場合だけ、成果物内の局所キーを使用する。局所キーはCRDD標準の安定コンテキストIDではなく、中央採番を必要としない。

## 網羅規則

- 必須の検証項目:
