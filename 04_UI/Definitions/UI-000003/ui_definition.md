UI ID: `UI-000003`
状態: Canonical
維持責任者: Qual-Lab

## 操作とFeedback

主要な操作・判断: 再試行する／回復する／清掃する。

| UX分析 | 利用者が行う判断・行動 | 重要な場面 | 必要なFeedback | 避ける失敗 |
