# UX-000025のUI分析

成果物種別: UI分析（UX観点）
分析単位: `UX-000025`
状態: 分析済み

## 1. 正式入力

- UX定義: [UX-000025 過去の推論情報と現在値を区別する](../../../02_UX/Definitions/UX-000025/ux_definition.md)

IAやREQを直接読んで不足を補完しない。この分析はUX定義から利用者観点だけを導き、情報構造はIA観点の分析に委ねる。

## 2. UIへ引き継ぐ利用者成果

| 観点 | UX定義から受け取る内容 |
|---|---|
| 利用者／利用状況 | 製品全体の利用者像にある「CRDD作成者・保守者」 |
| 利用のきっかけ | 過去判断を再利用または更新する時 |
| 目的 | 当時の仮説と現在有効な意図を区別する |
| 得たい結果 | 判断理由を追跡しつつ古い前提を現在値にしない |
| 独立した利用者成果 | 当時の仮説・判断・学びと現在有効な意図を区別し、必要な情報を選べる |
| 重要な場面 | 判断理由をAIへ渡す場面 |
| 避ける失敗 | 履歴を上書きし競合する理由を勝手に統合する |
| 守る品質 | 現行性・選択範囲・使用改訂版を追跡する |

## 3. 必要な認識・操作・Feedback

```text
過去判断を再利用または更新する時
        ↓
確認すること: 過去の情報、現在の意図、選択根拠を分ける
        ↓
利用者の目的: 当時の仮説と現在有効な意図を区別する
        │
        ├─ ★ 判断点: 判断理由をAIへ渡す場面
        ├─ ⚠ 避ける失敗: 履歴を上書きし競合する理由を勝手に統合する
        └─ ✓ 必要なFeedback: 現行性・選択範囲・使用改訂版を追跡する
        ↓
判断理由を追跡しつつ古い前提を現在値にしない
```

このUXからUIへ渡す中心は、特定の部品や内部処理ではなく、「判断理由をAIへ渡す場面」で利用者が「判断理由を追跡しつつ古い前提を現在値にしない」へ進める認識・判断・Feedbackである。

## 4. 状況による体験差

| 状況 | この利用者成果で必要な体験 |
|---|---|
| 利用開始 | 「過去判断を再利用または更新する時」で、対象と判断に必要な前提を理解できる |
| 成果成立 | 「判断理由を追跡しつつ古い前提を現在値にしない」を、現行性・選択範囲・使用改訂版を追跡するという条件で確認できる |
| 成果不成立 | 「履歴を上書きし競合する理由を勝手に統合する」を避け、理由と安全な戻り先を理解できる |
| 判断不能 | 不明な事実を補完せず、何を確認しなければ判断できないか分かる |

上表にない処理中、取消、回復その他の状態を、共通テンプレートだけを根拠に追加しない。必要性はこのUXの意味とIA観点の情報構造をUI定義で統合して判断する。

## 6. IA観点との統合時に確認すること

IA観点の分析が「過去の情報、現在の意図、選択根拠を分ける」を識別・状態・関係・可視性・導線として表現できるかを確認する。UI定義では「遡及上書き、古い仮説の現在値化および履歴全量の無選択投入を反証する」を確かめられる形を保つ。必要情報をここで推測して先取りしない。

### UX-000025から継承する確認事項

正式入力: [UX-000025](../../../02_UX/Definitions/UX-000025/ux_definition.md)

未確認事項は、統合元の要求ごとに次を保持する。

- REQ-000029: CRDD作成者・保守者が「当時の仮説と現在有効な意図を区別する」を行う際の判断基準、許容負担、利用環境および失敗後の選択
- 現在判定: 後続の実利用確認が必要。現在のUX定義をCanonical化する判断を止める事項ではない。
- 確認事項: REQ-000029: CRDD作成者・保守者が「当時の仮説と現在有効な意図を区別する」を行う際の判断基準、許容負担、利用環境および失敗後の選択
- 判断者: CRDD作成者・保守者を代表する利用者とQual-Lab。
- 未確認時の影響: 利用者成果、重要場面、失敗および品質期待を仮説として保持し、定量条件や実現方式を確定しない。
- Discoveryへ戻す条件: 想定した利用者、問題、望ましい変化または制約が誤っていると判明した場合。
- UX分析へ戻す条件: 利用場面、目的、得られる結果、重要場面、失敗または品質期待の統合判断が変わる場合。

再評価契機: 対象利用者による実利用確認、前提変更、または後続工程でこの未確認事項が成立条件へ影響すると判明した時。
